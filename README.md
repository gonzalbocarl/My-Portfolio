# Carl Gonzalbo — Portfolio

A deliberately restrained, editorial portfolio shell built with semantic HTML, CSS, and vanilla JavaScript.

## Current state

The UI is complete and intentionally uses placeholder copy/content. Real portfolio information, project images, links, and contact details can be dropped in without changing the visual system.

### Included

- Two-color visual system
- Responsive desktop/mobile layout
- Scroll reveal animation
- Subtle hero parallax
- Magnetic links and custom cursor on fine pointers
- Project and experience hover interactions
- Mobile navigation
- Reduced-motion support
- Custom favicon and 404 page
- GitHub Pages-ready static structure
- No framework or build step required

## Files

- `index.html` — page structure and placeholder content
- `styles.css` — complete visual system and responsive styles
- `script.js` — motion and interaction layer
- `favicon.svg` — minimal site mark
- `404.html` — custom fallback page
- `.nojekyll` — GitHub Pages compatibility
- `robots.txt` — crawler rules

## Next phase
